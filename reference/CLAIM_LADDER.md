# Technical Claim Ladder & Skill Boundaries

This document defines what technical proficiencies can be claimed in CVs, cover letters, and technical answers, categorized by depth of ownership.

---

## 1. Tier 1: Daily Production Ownership (Claim with full authority)

Technologies, frameworks, and paradigms designed, built, and shipped to live end-users:
- **Languages:** TypeScript, JavaScript, Python, PHP (Laravel), SQL, HTML/CSS.
- **Frontend & Full-Stack:** Next.js (App Router, Server Actions), React, Node.js, Tailwind CSS, Supabase, PostgreSQL.
- **AI & LLM Orchestration:** Claude Code, Claude API (Anthropic), OpenAI API, prompt engineering, RAG architectures, document extraction pipelines, multi-step agent flows, human-in-the-loop review, confidence-based escalation.
- **Workflow & Automation Tools:** n8n, Make, REST APIs, Webhooks, Playwright, Git/GitHub.
- **Integrations:** OfficeRnD, Nexudus, Google APIs, Sendgrid, CRM/GTM automated pipelines.
- **Architectural Operations:** Live system data migration off legacy stacks to modern codebases, marketplace architectures.

---

## 2. Tier 2: Working Knowledge (Claim as working knowledge / secondary tool)

Technologies understood conceptually, tested in development or integrated as secondary services:
- **Backend & APIs:** FastAPI, Flask, Docker, Kubernetes (basic deployment/containerization), Redis, Celery.
- **ML Tooling:** PyTorch (fine-tuning existing open models, embeddings generation, automated evaluation harnesses).

---

## 3. Tier 3: Off-Limits (NEVER claim, mention, or hallucinate)

Do not claim proficiency, production experience, or familiarity with the following:
- **Low-Level Cloud Infrastructure:** Enterprise AWS/GCP/Azure multi-region VPC/IAM principal administration.
- **Niche Enterprise Architectures:** BPMN engines, Camunda, Salesforce Apex development, SAP ABAP.
- **Computer Vision & Hardware:** Edge devices, embedded firmware, OpenCV, YOLO model training.
- **Pure ML Research:** Novel transformer architecture design, mathematical loss function research.
- **Languages:** Fluent German, French, Spanish, Polish, Dutch, Swedish, Danish (Candidate speaks English C2, Hindi Native, and Italian Conversational B1-B2).
- **Previous Platform Names:** Never mention "Bubble" or "no-code" by name; always refer to past migrations as "migrated off a legacy stack".
