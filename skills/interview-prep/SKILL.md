# Skill: Interview Preparation Generator

## Overview
Generate comprehensive, requisition-specific interview preparation kits covering system design, live coding scenarios, API architecture, RAG pipelines, and behavioral questions.

## Procedure

1. **Requisition & Company Analysis:**
   - Ingest target company mission, stack, and domain (e.g. Fintech, Supply Chain, MarTech, Developer Tools).
   - Identify primary technical assessment tracks (e.g., Python/FastAPI async services, LangGraph multi-agent pipelines, PostgreSQL indexing, API integrations).

2. **Generate Technical Architecture Pack:**
   - **System Architecture Deep-Dive:** Draw Mermaid diagrams illustrating the candidate's production experience at FlowSpace.co (real-time Nexudus/OfficeRnD connectors, RAG escalation) or open-source `llm-doc-parser`.
   - **API & Integration Design:** Walk through webhook idempotency, retry mechanisms with exponential backoff, rate limiting, and schema migration strategies.
   - **Agentic AI & RAG Deep-Dive:** Explain chunking strategies, vector embeddings (pgvector), confidence score thresholds, and fallback human escalation loops.

3. **Generate Live Coding Scenarios:**
   - Provide Python / TypeScript problem slices with test cases (e.g., async batch processor, schema validator, streaming parser).
   - Demonstrate clean, production-grade code adhering to candidate's claim ladder.

4. **Behavioral & Career Narrative:**
   - Structure STAR responses highlighting:
     - 0-to-1 feature delivery and 99.9% uptime maintenance at FlowSpace.co.
     - Cross-functional QA collaboration at Clubee.
     - Autonomous problem-solving with Claude Code.
     - Work authorization clarity (Italian EU Long-Term Resident, permanent resident, no visa sponsorship needed in Italy / EU remote).
